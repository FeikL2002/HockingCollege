# Hocking College | Cybersecurity & Networking Portfolio

Coursework, reference notes, small programs, and lab documentation collected by **Lewis Joseph Feik** while studying cybersecurity and networking at Hocking College.

The collection shows the foundations behind my software projects: understanding networks, working with Linux, interpreting security evidence, and explaining technical decisions. Materials are organized by subject and course week so visitors can follow a topic from notes to supporting artifacts.

## How to review the work

1. Open a subject folder, then choose a week or topic.
2. Read the Markdown notes in GitHub; open the linked PDFs or images for supporting artifacts.
3. Treat lab observations as records of the environment and date described in the individual artifact.

To browse locally:

```bash
git clone https://github.com/FeikL2002/HockingCollege.git
cd HockingCollege
```

Python examples require Python 3. Review each file before running it; requirements and expected input vary by exercise. Networking labs may depend on the course's simulator or lab environment.

## About this collection

This is a learning portfolio. Some folders contain working notes, historical assignments, or placeholders, and individual materials may reflect older software versions. Read each document or screenshot alongside its stated task, environment, and date.

The repository includes course-related material. No repository-wide license is currently included; consult the ownership and usage terms of individual materials before reusing them.
